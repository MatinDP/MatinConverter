# Matin Converter 1.0.0

تبدیل‌کنندهٔ آفلاین تصاویر برای Windows x64، بازنویسی‌شده با C#، .NET 10 و WPF. رابط فارسی و انگلیسی، پوستهٔ روشن/تیره/سیستم و دو بخش «تبدیل» و «تنظیمات» دارد.

تصاویر را انتخاب یا رها کنید؛ پوشه‌ها با گزینهٔ بررسی زیرپوشه‌ها اضافه می‌شوند. فرمت‌های خروجی مطابق رمزگذارهای موجود Magick.NET نمایش داده می‌شوند: JPEG، PNG، WEBP، AVIF، BMP، TIFF، GIF، ICO و چند فرمت اضافی. ورودی JFIF و گزینهٔ All files در انتخاب‌گر موجود است. پشتیبانی فایل‌های RAW و فرمت‌های خاص به رمزگشای واقعی همان بسته بستگی دارد و خطای کدک برای هر فایل جداگانه نمایش داده می‌شود.

موتور این نسخه Magick.NET Q8 است و پردازش کانال‌های رنگ را با دقت ۸ بیت انجام می‌دهد؛ برای گردش‌کار آرشیوی ۱۶ بیت و RAW بدون افت دقت طراحی نشده است. فایل اصلی در هر حالت حفظ می‌شود.

تبدیل اصلی را از پنجرهٔ برنامه یا گزینهٔ `Convert with Matin Converter` در منوی کلاسیک Explorer انجام دهید. تنظیمات کلیک‌راست ابتدا از پیش‌فرض‌های عمومی استفاده می‌کنند و پروفایل مستقل هم دارند. فقط یک پردازشگر موقت و یک پنجرهٔ پیشرفت در هر لحظه برای صف درخواست‌ها فعال است؛ هیچ سرویس دائمی نصب نمی‌شود.

## ساخت

نیازمندی‌ها: Windows x64، SDK .NET 10.0.403 یا جدیدتر، و Zig 0.15.2 برای DLL کوچک Shell. نیازی به نصب Visual Studio برای ساخت یا اجرای خروجی نیست.

Zig را از [توزیع رسمی 0.15.2](https://ziglang.org/download/0.15.2/zig-x86_64-windows-0.15.2.zip) دریافت کنید. SHA-256 آرشیو:

`3a0ed1e8799a2f8ce2a6e6290a9ff22e6906f8227865911fb7ddedc3cc14cb0c`

متغیر `ZIG_EXE` باید مسیر `zig.exe` باشد؛ اسکریپت مسیر ابزار محلی `%USERPROFILE%\.local\share\MatinBuildTools\zig-x86_64-windows-0.15.2\zig.exe` را هم می‌شناسد.

```powershell
.\scripts\build.ps1                 # native bridge, build, tests, self-contained application
.\scripts\build.ps1 -ShellTests     # also exercises real Shell COM + queue (temporarily registers test build)
.\scripts\build.ps1 -Installer      # also creates an EXE installer; run only when an installer is wanted
```

خروجی مستقل پس از ساخت: `artifacts/app-1.0.0/MatinConverter.exe` (کل پوشه باید کنار آن باشد). نصاب، فقط پس از درخواست ساخت: `artifacts/Matin-Converter-Setup-1.0.0.exe`.

برای توسعه، ابتدا `scripts/build-native.ps1` و سپس `dotnet run --project src/MatinConverter.Windows` را اجرا کنید. `dotnet test tests/MatinConverter.Tests` آزمون‌های موتور و تنظیمات را اجرا می‌کند.

ساخت نصب‌کننده از [Inno Setup 7.1](https://jrsoftware.org/isdl.php) استفاده می‌کند. متغیر `INNO_ISCC` را به مسیر `ISCC.exe` تنظیم کنید؛ مسیر محلی `%USERPROFILE%\.local\share\MatinBuildTools\InnoSetup-7.1.0\tools\ISCC.exe` هم شناخته می‌شود. کامپایلر جزئی از خروجی برنامه نیست. نصاب برای Windows x64 نسخهٔ ۲۰۰۴ یا جدیدتر ساخته می‌شود؛ استفاده از نسخه‌ای که همچنان به‌روزرسانی امنیتی دریافت می‌کند توصیه می‌شود.

`scripts/verify-installer.ps1` نصب، تبدیل واقعی، میانبرها، ثبت Shell و حذف نصب را در حساب کاربر آزمایش می‌کند. این آزمون فقط وقتی اجرا می‌شود که نصب دیگری در پوشهٔ مقصد وجود نداشته باشد و تنظیمات قبلی را در پایان برمی‌گرداند.

آزمون واقعی رابط: `dotnet run --project tests/MatinConverter.UiTests -c Release`. این آزمون فهرست ۱۰۰ تصویر، مجازی‌سازی، هر دو زبان و پوسته، اندازهٔ کوچک پنجره و تبدیل دستی با پنجرهٔ پیشرفت را بررسی می‌کند.

## ایمنی و رفتار خروجی

- همهٔ فایل‌های ورودی یک دسته، حتی در حالت overwrite و فرمت یکسان، حفظ می‌شوند. بررسی شناسهٔ فایل ویندوز پیوندهای همان فایل را هم محافظت می‌کند. پیش‌فرض برخورد نام‌ها شماره‌گذاری است.
- خروجی ابتدا در فایل موقت هم‌پوشه نوشته و اعتبارسنجی می‌شود؛ سپس با rename نهایی منتشر می‌شود. لغو، فایل موقت همان تبدیل را پاک می‌کند.
- متادیتا به‌صورت پیش‌فرض حفظ و جهت تصویر اصلاح می‌شود. گزینهٔ حذف متادیتا مستقل است. JPEG روی رنگ انتخاب‌شده تخت می‌شود.
- همهٔ فریم‌ها در خروجی سازگار حفظ می‌شوند. برای خروجی تک‌فریم، تصویر چندفریمی خطا می‌دهد مگر «فقط فریم اول» انتخاب شده باشد.
- حداکثر ۱۰۰ مگاپیکسل مجموع فریم‌ها، ۲۵۶ فریم و ضلع ۳۲۷۶۸ پیکسل؛ حافظه و فضای موقت موتور محدود است. پردازش موازی محدود و قابل تنظیم است.
- پوشهٔ یکسان با ورودی و زیرپوشه برای هر منبع جداگانه محاسبه می‌شود. پوشهٔ سفارشی برای همهٔ منابع مشترک است. پیش از ساخت پوشهٔ سفارشی ناموجود در تبدیل دستی سؤال می‌شود؛ کلیک‌راست آن را خودکار ایجاد می‌کند.
- تنظیمات و گزارش‌ها در `%LOCALAPPDATA%/MatinConverter` هستند. نوشتن JSON اتمی است؛ تنظیمات خراب پشتیبان‌گیری و با پیش‌فرض‌ها بازیابی می‌شوند.

## نصب و محدودیت‌های تأیید

نصاب per-user است، زمان اجرا و کتابخانهٔ بومی تصویر را همراه دارد، و ویژگی‌های کلیک‌راست و میانبر Desktop قابل انتخاب‌اند. حذف نصب، ثبت Shell و فایل‌های نصب‌شده را پاک و تنظیمات شخصی را حفظ می‌کند. Windows ممکن است برای DLL باز در Explorer تکمیل حذف را به restart موکول کند. نصاب امضای دیجیتال ندارد.

منو در Windows 10 کلاسیک و در Windows 11 زیر Show more options قرار دارد. این پروژه رفتار منوی مدرن Windows 11 را دست‌کاری نمی‌کند. وضعیت آزمون‌های فیزیکی و نصب روی ماشین پاک در [TESTING.md](TESTING.md) مستند شده است؛ موفقیت آزمون‌های خودکار به معنی تأیید یک ماشین Windows 10 آزمایش‌نشده نیست.
