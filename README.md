# Matin Converter

ابزار دسکتاپ آفلاین برای تبدیل تصاویر در Windows با Electron، React، TypeScript و Sharp. رابط برنامه فارسی و راست‌چین است و فایل‌های اصلی را تغییر نمی‌دهد.

## قابلیت‌ها

- ورودی JPEG/JFIF، PNG، WebP، AVIF، TIFF، GIF و SVG؛ خروجی JPEG، PNG، WebP، AVIF، TIFF و GIF
- تبدیل چند فایل، تنظیم کیفیت و ابعاد، و محدودکردن تقریبی حجم خروجی
- حفظ چرخش EXIF، حذف Metadata به‌صورت پیش‌فرض و نوشتن امن فایل خروجی
- پروفایل تبدیل سریع و تنظیمات محلی ماندگار
- پوستهٔ روشن، تیره و همگام با ظاهر Windows؛ تنظیم زوم رابط
- به‌روزرسانی نسخه از GitHub
- منوی کلاسیک راست‌کلیک اختیاری با ثبت per-user در Windows 10 و بخش «نمایش گزینه‌های بیشتر» در Windows 11

تصاویر متحرک یا چندصفحه‌ای برای جلوگیری از حذف فریم‌ها پذیرفته نمی‌شوند.

## توسعه و ساخت

نیازمند Node.js 20+ و npm است. ابتدا `npm install` را اجرا کنید.

- `npm run dev` اجرای محیط توسعه
- `npm run typecheck` بررسی TypeScript
- `npm test` اجرای تست‌ها
- `npm run build` ساخت برنامه
- `npm run dist:win` ساخت نصاب NSIS برای Windows x64
- `npm run native:win` ساخت افزونهٔ Explorer؛ نیازمند Visual Studio C++ Build Tools و Windows SDK

## انتشار و به‌روزرسانی

ریلیزهای رسمی در [GitHub Releases](https://github.com/MatinDP/MatinConverter/releases) قرار می‌گیرند. برای به‌روزرسانی خودکار Windows، Release باید فایل نصاب NSIS، فایل `.blockmap` و `latest.yml` همان ساخت را داشته باشد. راهنمای انتشار در [UPDATING.md](UPDATING.md) آمده است.

منوی راست‌کلیک فعلی با ثبت per-user در رجیستری کار می‌کند و برای نصب یا استفاده به گواهی نیاز ندارد. گزینه در منوی اصلی جدید Windows 11 قرار نمی‌گیرد؛ از «نمایش گزینه‌های بیشتر» در دسترس است. اتصال Shell Extension مدرن مبتنی بر MSIX در این نسخه ارائه نمی‌شود.

## حریم خصوصی

پردازش تصویر روی رایانهٔ خود کاربر انجام می‌شود. برنامه برای تبدیل تصاویر به اینترنت نیاز ندارد؛ فقط بررسی یا دریافت نسخهٔ جدید به اتصال اینترنت نیاز دارد.
